# Phase 3: Real-Time Translation Integration

## Goal

Move from a placeholder demo loop to live sign recognition with stabilized text and speech output.

## Deliverables

- live inference path wired to the trained model
- debouncing and smoothing tuned for a real demo
- speech output integrated with fallback behavior

## Exit Criteria

- supported signs are recognized in real time
- translated text remains stable on screen
- speech output works or degrades gracefully
