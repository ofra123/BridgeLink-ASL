# Phase 2: Data Pipeline And Baseline Model

## Goal

Replace the phase-1 placeholder emphasis with a reproducible dataset workflow and a model artifact that can be evaluated offline.

## Deliverables

- landmark extraction workflow
- training split and labeling conventions
- collected or curated training samples
- baseline model artifact and evaluation report

## Exit Criteria

- the model reaches a usable held-out accuracy target
- saved artifacts load back into the app pipeline
- the team can explain how the dataset was prepared
